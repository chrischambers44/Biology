⚙️ Setup Guide — How this site works

1
GitHub Pages: This site is hosted directly from the Biology GitHub repository. Go to Settings → Pages → Source: Deploy from branch → main → / (root) and save. Your site will be live at https://yourusername.github.io/Biology/
2
Cloudflare Worker (for AI marking): The quiz uses Claude AI to mark answers. Because of browser security rules (CORS), it needs a small proxy. Create a free account at workers.cloudflare.com, create a new Worker, and paste in the code from worker.js in this repo.
3
Update the proxy URL: Once your Worker is deployed, you'll get a URL like https://biology-proxy.yourusername.workers.dev. Open quiz.html and update the PROXY_URL constant near the top of the script section.
4
API Key: You'll need an Anthropic API key from console.anthropic.com. It costs only a few pence per quiz attempt. The key is entered on the quiz page and never stored on any server — it goes directly from the browser to your Cloudflare Worker, which forwards it to Anthropic.
5
(Optional) Lock down the Worker: In worker.js, update the ALLOWED_ORIGIN constant from '*' to your actual GitHub Pages URL to prevent anyone else using your proxy.
